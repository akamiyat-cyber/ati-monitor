How to use / help
  1. Each site uses its own copy of 3F4D_Water_Monitor_Sheet_TEMPLATE.xlsx (button "Download sheet template" above) converted to a Google Sheet: upload it to Google Drive, open it and choose File > Save as Google Sheets.
  2. The site shares the sheet: Share > General access > Anyone with the link > Viewer, and sends you the link.
  3. Paste the link above and press "Add site". Repeat for every site. The list is kept in this browser; "Share this list" makes a link that opens the same list on another device.
  4. "Compare sites" draws all sites in the same graphs (x axis: days after transplanting or date). "Each site" shows the graphs of every site separately, with the MD, Pitan and 3F4D periods.
  5. Works offline: the app and the data of the last successful load are kept on this device. Without internet the graphs show the saved data (marked "Offline"). Install it with the browser menu: "Add to Home screen" / "Install app".
  6. The data are read from the tab Viewer_export (or Data_Farmer) each time you press "Load / refresh all". The sheets are never changed.

If a site shows "Could not read": check the sharing setting, and that the sheet is the 3F4D Water Monitor sheet version (tab Data_Farmer).
