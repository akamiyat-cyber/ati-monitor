3F4D Site Viewer - demo sheets (3 example sites)

Use them to practise steps 2 to 5 of the 3F4D Site Viewer:
1. Upload the 3 files to Google Drive. Open each one and choose File > Save as Google Sheets.
2. In each Google Sheet: Share > General access > Anyone with the link > Viewer > Copy link.
3. In the viewer, paste each link (step 4) and press "Add site", then "Load / refresh all".
